# 무게와 들이 탐구실

초등학교 3학년 2학기 「4. 무게와 들이」 수업용 조작 사이트입니다. 외부 라이브러리·회원가입·설치가 필요 없는 정적 HTML/CSS/JavaScript로 만들었습니다.

## 시작하기

압축을 풀고 `index.html`을 브라우저로 여세요. 인터넷 없이도 여섯 활동을 사용할 수 있습니다. 브라우저 환경에 따라 로컬 파일 기록 저장이 제한될 수 있으므로 기록을 CSV로 내려받을 수 있습니다.

## GitHub Pages로 게시하기

1. GitHub에서 사용할 저장소를 엽니다. 새 저장소를 만들어도 됩니다.
2. **Add file → Upload files**에서 이 폴더 안의 `index.html`, `style.css`, `app.js`를 저장소 최상위에 업로드하고 커밋합니다. 폴더 자체가 아니라 폴더 안의 파일을 올립니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. `main` 브랜치, `/(root)` 폴더를 선택하고 **Save**합니다. 실제 기본 브랜치 이름이 다르면 해당 브랜치를 고릅니다.
5. 게시가 완료되면 Pages 설정 화면의 사이트 주소를 학생들에게 안내합니다.

GitHub의 계정·저장소 설정에 따라 Pages 사용 조건이나 메뉴가 다를 수 있습니다. 아직 GitHub 저장소에 업로드하거나 게시하지 않았습니다.

게시 절차 참고: [GitHub 공식 Pages 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 활동 구성

| 활동 | 조작 | 관찰할 내용 |
| --- | --- | --- |
| 양팔저울 | 물건 선택 → 저울 움직이기 | 무거운 쪽 접시가 내려감 |
| 클립 | 같은 클립을 하나씩 더하거나 빼기 | 수평일 때 클립의 개수 비교 |
| 바둑돌 | 같은 바둑돌을 하나씩 더하거나 빼기 | 수평일 때 바둑돌의 개수 비교 |
| 물병 | 가득 찬 물병의 물을 다른 빈 물병으로 옮기기 | 남은 물이나 빈 공간으로 비교 |
| 종이컵 | 같은 컵에 가득 담은 물을 한 컵씩 붓기 | 가득 채우는 데 필요한 컵 수 비교 |
| 요구르트병 | 같은 요구르트병에 가득 담은 물을 한 병씩 붓기 | 가득 채우는 데 필요한 병 수 비교 |

각 활동에 예상 선택, 관찰 피드백, 결론 확인, 설명 쓰기, 기록 저장 기능이 있습니다. ‘지도서 예시’, ‘더 탐구하기’, ‘같은 양 비교’의 세 꾸러미를 제공합니다. 기록은 현재 브라우저에 최대 100개만 저장되고, CSV 다운로드·인쇄·전체 삭제를 지원합니다. 이름이나 학급 정보는 수집하지 않으며 서버로 기록을 전송하지 않습니다.

## 첨부 지도서 반영 내용

사용자가 제공한 지도서 234~235쪽(2차시), 244~245쪽(6차시)을 참고했습니다. 삽화를 복사하지 않고 조작용 그림으로 새로 구성했습니다.

| 활동 | 지도서 예시 꾸러미 | 정리 |
| --- | --- | --- |
| 양팔저울 | 연필·지우개 | 지우개 쪽이 내려가므로 더 무거움 |
| 클립 | 연필 8개, 지우개 15개 | 지우개가 클립 7개만큼 더 무거움 |
| 바둑돌 | 풀 13개, 빈 물통 10개, 가위 15개 | 가위 → 풀 → 빈 물통 |
| 물병 | 물병 가·나 | 가의 물을 나로 옮겨도 빈 공간이 남음. 같은 수조에 모두 옮기면 나의 물 높이가 더 높음 |
| 종이컵 | 물병 가 3컵, 물병 나 5컵 | 나에 종이컵 2컵만큼 더 들어감 |
| 요구르트병 | 생수병 5병, 물뿌리개 20병, 분무기 8병 | 물뿌리개 → 분무기 → 생수병 |

바둑돌·요구르트병의 지도서 예시에서는 세 물건을 모두 측정해야 결론을 확인할 수 있습니다. ‘생각을 넓혀요’에서 세 물건의 순서도 고를 수 있습니다. 물병 비교에서는 ‘같은 수조에 모두 옮겨 보기’ 버튼으로 간접 비교도 할 수 있습니다.

단위 활동에는 서로 다른 단위의 개수만으로는 양을 비교할 수 없음을 확인하는 질문과, 단위 크기에 따라 측정값이 달라지고 표준 단위가 필요하다는 정리를 넣었습니다. 교사용 안내에는 관찰·구술 평가와 어려움을 겪는 학생을 위한 피드백을 포함했습니다. 양손으로 들어 보기와 실제 교구로 측정하는 활동은 교실에서 함께 진행해 주세요.

## 교육과정 및 검토 상태

2022 개정 교육과정의 무게·들이 측정을 위한 직접 비교 및 임의 단위 측정 기초 활동으로 구성했습니다. 표준 단위(g, kg, L, mL), 단위 관계, 덧셈·뺄셈을 다루는 단원 전체 자료는 아닙니다.

- 근거: [교육부 고시 제2022-33호, 별책 8 수학과 교육과정](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=)
- 참고한 지도서 범위: 사용자가 첨부한 수학 지도서 3-2, 234~235쪽·244~245쪽. 이외의 차시는 확인하지 않았습니다.
- 지도서 예시의 개수는 해당 활동의 학습 모델입니다. 실제 제품마다 값이 다를 수 있습니다. 나머지 꾸러미는 확장용 가상 값이며 용기 그림의 높이·넓이는 축척이 아닙니다.
- 단위 활동의 두 물건·용기에는 항상 같은 단위를 사용합니다. 단위가 다르면 개수만으로 비교할 수 없음을 지도해 주세요.

## 수정하기

`app.js`의 `weightSets`, `volumeSets`, `guideStones`, `guideYogurt`에서 물건·용기와 내부 수치를 바꿀 수 있습니다. 클립 활동은 1단위, 바둑돌 활동은 2단위를 사용하며, 단위 수는 최대 20개입니다. 바둑돌 활동에 사용할 무게 값은 2로 나누어떨어지도록 설정합니다. 종이컵 활동의 들이 값은 60단위, 요구르트병 활동은 30단위로 나누어떨어지도록 설정합니다. 내부 수치는 실제 g·mL로 표시하지 않습니다. 활동마다 독립적인 예시이므로 서로 다른 활동의 내부 값을 실제 단위처럼 환산하지 않습니다.

`index.html`에서 안내 문구를, `style.css`에서 화면 디자인을 바꿀 수 있습니다. CSS와 JS 경로는 상대 경로여서 GitHub Pages의 프로젝트 하위 주소에서도 사용할 수 있습니다.

## 확인한 범위

JavaScript 문법과 6개 활동 × 3개 꾸러미의 비교 결과, 지도서 수치, 같음 처리, 양방향 물 옮기기, 같은 수조 비교, 세 물건의 측정 완료 조건과 순서 확인, 서로 다른 단위의 비교 질문, 잘못된 결론의 저장 방지, 기록 저장과 입력값의 HTML 이스케이프를 점검했습니다. 환경의 연결 제한 때문에 실제 브라우저에서의 화면 배치와 인쇄·CSV 다운로드는 직접 확인하지 못했습니다. 수업 전 사용할 기기에서 한 번씩 확인해 주세요.
